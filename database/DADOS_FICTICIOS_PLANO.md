# Plano de massa de dados fictícios

O MVP terá inicialmente 24 clientes fictícios, distribuídos para tornar o dashboard útil:

- 8 jornadas saudáveis;
- 8 em atenção;
- 5 necessitando acompanhamento;
- 3 concluídas para alimentar CSAT/NPS.

Os cenários incluirão:
- documentação completa;
- documento pendente recente;
- múltiplas pendências;
- ausência de interação;
- jornada avançando normalmente;
- preparação para contratação;
- jornada interrompida com motivo fictício;
- feedback positivo, neutro e negativo.

Nenhum nome, CPF, renda, telefone, endereço ou documento será derivado de clientes reais.

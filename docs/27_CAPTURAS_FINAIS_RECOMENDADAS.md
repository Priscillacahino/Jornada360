# Capturas finais recomendadas — Jornada360

As imagens finais devem ser feitas depois do acabamento visual definitivo.

## Capturas principais
1. **Sobre o case**
   - título;
   - pergunta de projeto;
   - solução;
   - números demonstrativos.

2. **Dashboard**
   - indicadores;
   - prioridades;
   - insight CX;
   - distribuição por etapa.

3. **Central de Prioridades**
   - cliente priorizado;
   - motivo;
   - próxima ação;
   - fatores explicativos.

4. **Cliente 360º**
   - progresso;
   - etapa;
   - Health Score;
   - checklist;
   - timeline.

5. **Explicação do Health Score**
   - decomposição dos fatores;
   - aviso de que não é score de crédito.

6. **Voz do Cliente**
   - CSAT;
   - NPS;
   - atritos;
   - comentários.

7. **Visão mobile do cliente**
   - progresso;
   - ação necessária;
   - próximo passo;
   - pesquisa.

## Formatos
Para portfólio:
- uma captura desktop ampla;
- uma captura mobile;
- 4 a 6 detalhes aproximados.

## Cuidados
- restaurar a massa fictícia antes das capturas;
- não inserir dados reais;
- não ocultar o aviso de independência/limites quando ele for relevante;
- usar o mesmo conjunto de dados em todas as capturas;
- conferir ortografia e alinhamento antes de registrar as imagens.

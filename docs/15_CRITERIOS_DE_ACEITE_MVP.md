# Critérios de aceite do MVP

## Cliente
- Deve identificar a etapa atual sem precisar interpretar termos técnicos.
- Deve visualizar se existe uma ação pendente.
- Deve compreender o próximo passo.
- Deve visualizar a data/tempo da última atualização.
- Não deve interpretar o Health Score como score de crédito.

## Profissional
- Deve localizar um cliente por nome.
- Deve filtrar jornadas por saúde.
- Deve identificar quem precisa de acompanhamento e o motivo.
- Deve visualizar a próxima ação sugerida.
- Deve consultar uma visão consolidada do cliente.

## CX/CS
- Deve haver CSAT, NPS, conclusão, interrupção e categorias de atrito no ambiente demonstrativo.
- Toda prioridade deve ser explicável.
- A ausência de pesquisa não deve punir automaticamente o Health Score.
- Dados pessoais sensíveis não devem participar da priorização.

## Privacidade e segurança
- Apenas dados fictícios no portfólio.
- Nenhuma credencial bancária, documento real ou informação de antigo cliente.
- Aviso explícito de independência institucional.
- IA não pode aprovar, reprovar ou inferir elegibilidade financeira.

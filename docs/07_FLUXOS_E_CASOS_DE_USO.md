# Fluxos e casos de uso — Jornada360

## Fluxo A — Profissional
Login demonstrativo → Dashboard → Central de Prioridades → Cliente 360º → identificar motivo → registrar interação/tarefa → atualizar pendência → timeline atualizada.

## Fluxo B — Cliente
Acesso demonstrativo → Minha Jornada → etapa atual → verificar “Preciso fazer algo?” → consultar documentos/pendência → visualizar próximo passo → acompanhar histórico.

## Fluxo C — Encerramento e CX
Jornada concluída → pesquisa CSAT → pós-atendimento → NPS/comentário → feedback registrado na Voz do Cliente → indicador agregado atualizado.

## Casos de uso prioritários do MVP

### UC01 — Consultar carteira
O profissional visualiza clientes, etapa, saúde da jornada, última interação e pendências.

### UC02 — Consultar Cliente 360º
O profissional acessa resumo, timeline, documentos, pendências, tarefas, interações e explicação do Health Score.

### UC03 — Resolver pendência
O profissional registra solução; o sistema atualiza status, timeline e pontuação relacionada.

### UC04 — Identificar prioridade
O sistema sinaliza jornada com atraso, pendência antiga ou ausência de interação e explica o motivo.

### UC05 — Acompanhar jornada pelo cliente
O cliente vê etapa atual, progresso, pendências e próximo passo sem visualizar controles internos.

### UC06 — Registrar percepção
O cliente responde CSAT/NPS e pode deixar comentário aberto.

## Fora do MVP
- integração bancária real;
- assinatura de contrato;
- consulta a bureaus de crédito;
- aprovação/reprovação de crédito;
- armazenamento de documentos pessoais reais;
- envio real de SMS/WhatsApp/e-mail.
